# GodOfPrompt 2.0 — Responsive Website Starter

Plain HTML, CSS and JavaScript responsive single-page website.

## Preview
Open `index.html` in a browser, or open this folder in VS Code and use Live Server.

## Official logo
Place the exact approved purple faceted crown image at `assets/godofprompt-logo.png`. Preserve the original proportions, silhouette, colour and internal geometry; do not stretch, crop, redraw or recolour it.

## Files
- `index.html` — website structure, SEO metadata and content
- `styles.css` — responsive desktop/tablet/mobile styling
- `script.js` — mobile navigation and dynamic copyright year
- `assets/` — approved brand assets

## Important before publishing
This is a front-end coding preview, not a live WordPress deployment or finished WordPress theme. Verify content and pricing, add approved project imagery, connect any enquiry form/CRM, add legal pages as needed, and test on real devices. The Standard plan deliverables have intentionally not been invented. Back up the existing WordPress site and preserve current URLs/SEO before integrating.
